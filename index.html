eBay Canada Automation V1 - Privacy Policy

Overview

eBay Canada Automation V1 ("Application") is a workflow automation tool designed to help sellers manage their eBay inventory and business operations more efficiently. This Privacy Policy explains how we access, use, and protect your data.

What Data Is Accessed

The Application retrieves eBay seller information through authorized API access, including:

  • Inventory listings and quantities
  • Listing prices and details
  • Order and fulfillment information
  • Account settings and policies

The Application does not request or intentionally collect eBay account passwords.

How Data Is Used

Information serves only authorized seller functions like:

  • Inventory management
  • Listing optimization
  • Order tracking and fulfillment
  • Price and policy monitoring

We do not use eBay information obtained through eBay APIs for purposes that are not authorized by the applicable user.

AI-Assisted Processing

Our automation workflows may use AI-assisted data analysis to:

  • Provide pricing recommendations
  • Suggest inventory management rules
  • Optimize listing visibility

eBay data is NEVER used to:

  • Train generative AI models or machine learning systems
  • Drive autonomous purchasing or listing decisions without human review
  • Aggregate competitive intelligence across multiple sellers

All AI recommendations require human review and approval before execution.

Third-Party Processing

The application uses Google Sheets and n8n automation services for workflow management. These services are contractually obligated to comply with eBay's API License Agreement and all applicable data protection laws.

We do not use eBay information obtained through eBay APIs to train, fine-tune, or improve third-party artificial intelligence models.

Data Location & Jurisdiction

  • Storage: Data is stored in Google Cloud infrastructure (US/multi-region)
  • Canada: Canadian users are protected under PIPEDA (Personal Information Protection and Electronic Documents Act)
  • European Union: EU users are protected under GDPR (General Data Protection Regulation)
  • Data Transfers: All transfers to processors are contractually governed by data processing agreements

User Control & Revocation

Users can revoke application access through eBay's authorization controls. After revocation, the application stops accessing your information immediately.

Data Retention & Deletion

Information is kept only "as long as necessary for the specific legitimate purpose." When no longer needed, data is deleted in accordance with eBay's requirements and applicable law.

Security

We implement reasonable safeguards to protect your data. Authentication credentials are not intentionally published through this website or stored in publicly accessible source files.

Data Breach Notification

In the event of unauthorized access to eBay data, we will:

  1. Investigate the incident immediately
  2. Notify affected users within 30 days
  3. Notify eBay developers program within 48 hours
  4. Implement corrective measures

Service Providers

This application uses the following data processors:

  • Google Sheets: Data storage and workflow records
  • n8n Cloud: Automation engine and API orchestration

Both are contractually obligated to comply with eBay's API License Agreement and applicable data protection laws.
